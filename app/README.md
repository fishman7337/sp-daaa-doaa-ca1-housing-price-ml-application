# App Package

The Flask application package lives here.

- `__init__.py`: application factory and extension registration.
- `config.py`: environment-aware configuration.
- `extensions.py`: shared Flask extension instances.
- `forms.py`: WTForms validation.
- `models.py`: SQLAlchemy models for users, predictions, and chat.
- `routes.py`: pages and JSON API endpoints.
- `services/`: model inference and preprocessing helpers.
