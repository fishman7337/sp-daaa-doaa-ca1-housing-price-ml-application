# Governance

EstateScope AI is maintained as an academic CA1 project by Goh Kun Ming for Singapore Polytechnic ST1516.

## Decision Making

Changes should prioritize:

- Correctness and reproducibility.
- Clear documentation for reviewers.
- Safe handling of credentials and local data.
- Traceable model and data changes.
- Passing CI before GitHub publication.

## Maintainer Responsibilities

- Keep README and runbooks current.
- Review dependency upgrades before merging.
- Avoid committing secrets, local databases, cache folders, and private data.
- Record model promotion decisions in `docs/mlops/` and `reports/metrics/`.

## Academic Integrity

All work should comply with Singapore Polytechnic academic integrity expectations. External sources, tools, or generated content should be acknowledged where required by module guidance.
