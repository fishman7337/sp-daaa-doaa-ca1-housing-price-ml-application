# Uploads And Demo Media

This folder currently contains bundled demo media used by templates and is also the default runtime upload folder.

Generated user uploads use randomized filenames and should not be committed.

The two largest tracked presentation assets are `hero-background.mp4` (48.54 MiB) and `signup-hero.mp4` (39.79 MiB). Their integrity is pinned in `artifacts-manifest.json`; new large media should be optimized or hosted externally.
