How it works

Tabular model: engineered features from 05_modelling.ipynb / src pipelines (beds, baths, house size, lot size in acres, city/state cleans, ratios like total_rooms, house_size_per_room, log1p sizes). Text head reads the cleaned listing description; image head uses brightness/texture as a simple proxy. Ensemble averages the modalities you supply.
