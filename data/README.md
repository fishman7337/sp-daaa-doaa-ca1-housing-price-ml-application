# Data

This folder contains lightweight, aggregated CSV files used by the dashboard APIs.

Current files:

- `usa_real_estate_price_time_series.csv`: 816 monthly aggregate rows spanning January 1901 through April 2026.
- `usa_real_estate_price_histogram.csv`: 200,000 price observations used by the distribution API.

Do not place secrets or private user records here. Large raw datasets should be stored externally or documented in the relevant data card.
